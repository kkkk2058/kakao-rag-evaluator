## 2. 진단

### 2-1. 채점식 역산 — 공식 keyfact_f1은 bag-of-tokens F1

per_question 10건을 여러 후보식과 대조:

| 후보식 | 공식 점수와 MSE |
|---|---|
| 답변 전체 vs key_facts 이어붙임, **어절 multiset F1** | **0.0022** |
| 같은 방식, 어절 **집합(set)** F1 | **0.0015** |
| 문자 bigram F1 | 0.0038 |
| key_fact별 F1의 평균 | 0.07~0.10 (불일치) |

→ **답변 전체를 하나의 토큰 가방으로 보고 key_facts 전체와 F1을 잰다.** 귀결 셋:

1. **누락과 군더더기가 같은 무게로 깎인다.** (기존 4번 셀은 recall만 봐서 절반만 보였다)
2. **어미·조사가 다르면 다른 토큰이다.** `금지되어 있으며` vs `금지됩니다` = 양쪽 1토큰씩 손해. 원문 표현 유지가 곧 점수.
3. **순서는 비용 0.** (판정어 위치 무관)

### 2-2. 손실의 정체 — 문항별 P/R 분해

| 문항 | F1 | P | R | 원인 |
|---|---|---|---|---|
| P07 | 0.333 | 0.44 | 0.21 | key_fact 3개 중 2개 누락(`회사가 아닌`, `제3자 미가입`), `들립니다` 비문 |
| P02 | 0.450 | 0.39 | 0.39 | **한 문장의 앞 절**(`복구하도록 노력하되,`) 통째 누락 + 질문 되풀이 |
| P08 | 0.452 | 0.80 | 0.27 | 조가 2문장(123자)인데 **앞 문장 통째 누락** |
| P09 | 0.468 | 0.37 | 0.65 | 안 물어본 `사용·저장·수정·복제…` 열거를 끌어옴 |
| P10 | 0.746 | 0.56 | 0.82 | 질문 되풀이·중복 서술 |

→ **리콜 손실 3건 + 정밀도 손실 2건.** 두 방향 모두 고쳐야 한다.

### 2-3. 천장 계산 (어절 F1 근사)

| 전략 | 평균 어절 F1 |
|---|---|
| 현행 답변 | 0.623 |
| 문장 단위 추출 | 0.747 |
| **절 단위 greedy oracle** | **0.815** |
| 손으로 쓴 목표 답변 10개 | 0.879 |

→ 목표 답변 형태: **"정답 조의 필요한 절을 빠짐없이, 원문 표현 그대로, 그 외엔 아무것도 안 쓴다."**

### 2-4. 왜 기존 커버리지 재시도(V7)가 못 잡았나

`_cov_find_missing`이 누락 3건을 모두 놓쳤는데 이유가 각기 달랐다:

- **P02** — 커버리지 단위가 *문장*. `…노력하되, 2시간 이상 …알려 드리겠습니다.`는 한 문장이라 뒤 절만 답해도 겹침이 `_COV_PRESENT=0.45`를 넘겨 **"이미 반영됨"으로 통과**.
- **P08** — 조가 2문장뿐인데 앞 문장의 질문 관련도가 하위 → 필수 후보 탈락.
- **P07** — 같은 사실 반복 문장이 `0.75 × top` 아래.

→ 셋 다 "관련도가 낮아서"가 아니라 **필수 판정을 관련도 하나로만 했기 때문.**

## 3. 수정 내용 (`결과기_최종.ipynb`)

### 3-1. 1번 셀 (결과기 본체)

| # | 변경 | 겨냥 |
|---|---|---|
| 1 | `_SYSTEM_PROMPT` 재작성 — 원문 통째 인용(1), 질문 되풀이 금지(2), `~하되,`로 이어지는 문장 전체 인용(3), 같은 규정의 다른 문장 동반(4), 안 물어본 열거 금지(5) | 전 문항 |
| 2 | `_split_coverage_units()` 신설 — 커버리지 단위 문장 → **절**. `~하되,/~하며,/~으며,` 뒤 추가 분할. 근거 머리글·목록 도입문(`…아래와 같습니다.`) 제외 | P02, P03 |
| 3 | `_cov_find_missing()` 재작성 — 필수 절을 **세 경로**로: (1) 질문 관련도, (2) 짧은 근거(220자 이하)면 전량, (3) 이미 인용한 절의 **형제 절**. 리랭커 없어도 어휘 폴백 동작(기존엔 통째 비활성) | P02·P07·P08 |
| 4 | `_COV_PRESENT` 0.45 → **0.56** | P02 |
| 5 | `_is_short_evidence()` + 짧은 조 전문 인용 지시 (합산 200자 이하) | P05, P08 |
| 6 | `_trim_long_structural_block()` — 400자 넘는 항은 문장 단위로 축소(목록 질문 제외) | P09 |

> 관련도 문턱(`_COV_REL_RATIO=0.75`, `_COV_ABS_MIN=0.45`)은 리랭커 스케일에 맞춰진 값이라 **손대지 않음.** 432조합 스윕 결과 채택값 주변이 넓은 평지.

### 3-2. 6번 셀 신설 (검증용, 제출물 아님)

keyfact F1 근사 채점 셀:
- 어절/집합 F1 + P/R 동시 출력
- 문항별 **[빠진 토큰]/[군더더기 토큰]** 표시 → 다음에 고칠 대상이 바로 보임
